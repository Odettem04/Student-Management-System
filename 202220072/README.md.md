
# Student Management System (SMS)

**Course:** Software Documentation and Development Lab

---

## Task 1: Conceptual Documentation

### Introduction

The Student Management System (SMS) is a simple system that helps schools manage student information. Users can add students, view their information, and delete students from the system.

### Purpose of the System

The purpose of this system is to make it easier to manage student records. Instead of writing student information on paper, the school can keep the records in one system. This makes it easier to find and update student information.

### Key Features

The system has three main features:

1. **Add Student:** Users can add a new student by entering the student's name and ID.

2. **View Student List:** Users can see all the students saved in the system.

3. **Delete Student:** Users can delete a student from the system using the student ID.

### System Users

The system is mainly used by school administrators and staff who are responsible for managing student information.

## Task 2: Procedural Documentation

### Procedure 1: How to Add a Student

1. Open the Student Management System.
2. Click on Add Student.
3. Enter the student's name.
4. Enter the student ID.
5. Check the information.
6. Click Save.

The new student will be added to the student list.

### Procedure 2: How to Delete a Student

1. Open the Student Management System.
2. Click on View Student List.
3. Find the student you want to delete.
4. Click Delete next to the student.
5. Confirm the deletion if needed.

The student will be removed from the list.

### Procedure 3: How to View Students

1. Open the Student Management System.
2. Click on View Student List.
3. The system will show the saved students.
4. You can check their names and IDs.

## Task 3: Reference Documentation

This table shows the main functions used in the Student Management System.

| Function | Input | Description |
|---|---|---|
| addStudent() | Name, ID | Adds a new student to the system. |
| viewStudents() | None | Shows all students in the system. |
| deleteStudent() | ID | Deletes a student using their ID. |

### Function Details

**1. addStudent()**

This function is used to add a new student. The user enters the student's name and ID, and the system saves the information.

**2. viewStudents()**

This function shows the list of students. It does not need any input from the user.

**3. deleteStudent()**

This function is used to remove a student. The user selects the student or enters the student ID to delete the record.
